2026-10-21（America/Los_Angeles）供创始人讨论
一句话

看乐不再以“卖了多少节课”衡量自己，
而以“有多少合格的老师在按看乐的方法教、
有多少学生因此真正进步”衡量自己。

平台是推广教学法的工具，不是目的。

PRD §12
前因 ①　行业现实

音乐教育陷在一个恶性循环里

老师自己没理解透→ 教不对→ 学生学不好→ 归因“没天赋”→ 放弃 / 不敢学→ 行业整体走弱

天赋论与成名论

学不好怪天赋，学音乐是为了成名或加分。音乐没有被当作与数理化同等的基础素养。

师资质量参差

大量老师原理没吃透、技艺有欠缺，教学凭经验和模仿。

缺少“怎么教”的标准

考级回答“考什么”，很少回答“每节课该怎么教、每一步该达到什么”。

PRD §2.13
前因 ②　看乐现实

门店模式能活，但改变不了全民素质

重资产

租金、装修、人员成本高，单店复制慢、风险大。

获客难

依赖地推和口碑，半径有限、成本高。

影响力天花板

一家机构能覆盖的学生，相对全民素质的目标微不足道。

唯一不可复制的资产

看乐的教学理念与方法，以及认同它的老师和学生。

所以重中之重是推广教学法、培训师资，而不是多卖几节课。

PRD §2.24
创始人的设想

轻资产：认证老师 + 统一品牌 + 统一结算

师资培训学习看乐教学法
→
体系认证考核通过获得认证
→
加盟平台成为看乐认证老师
→
就近约课机构琴房、临时场地等
→
看乐结算统一收款、统一分账

轻资产扩张

场地和教师的固定成本交给加盟方。

推广教学法

每一位认证老师都是体系的传播节点。

“学生在跟看乐学”

统一收款，解决财务问题，也掌握数据。

PRD §2.35
核心判断 ①

这其实是两门生意：A 是目的，B 是手段

A　目的

推广体系、认证师资

  • 本质：标准输出，类似奥尔夫、柯达伊、铃木、英皇
  • 壁垒：教学法、分级标准、认证公信力
  • 风险：体系能否标准化、培训产能
  • 与理念：直接对齐
B　手段

就近约课撮合

  • 本质：双边市场，类似家教 O2O
  • 壁垒：本地老师密度、获客效率
  • 风险：冷启动、跳单、获客成本
  • 与理念：不加约束会把指标拉回“课时数”

顺序必须是 体系 → 工具 → 撮合，反过来大概率卡在冷启动、跳单与质量失控。

PRD §3.16
核心判断 ②

飞轮：每个功能都要能指出它推动了哪一环

可考核的体系
认证有公信力
老师按体系教
学生进步可见
品牌被信任
更多老师与学生

如果反过来

没有可考核的体系 → 认证只能看感觉 → 变成卖证 → 品牌被稀释。

如果没有过程数据

无法证明“跟看乐学更有效” → 学生没理由通过平台 → 跳单。

如果没有本地密度

就近约课约不到人 → 学生流失 → 老师没生源 → 老师流失。

PRD §3.27
机会

为什么值得做

01

“怎么教”的标准是空位

市场不缺考试标准，缺的是教学过程标准，以及证明教学有效的过程数据。

02

独立老师的真实痛点

缺方法、缺生源、缺背书，还要自己收款排课。体系＋生源＋工具＋结算一起打包。

03

小机构的真实痛点

有场地有学生，缺教研和差异化品牌。“看乐认证机构”可以成为招生卖点。

04

复制速度取决于培训

体系标准化后，扩张受培训产能约束，而不是门店资金。

05

常态化带来增量人群

触达因为“我没天赋”而不敢学的成人和普通家庭；小组课天然匹配。

注

以上是方向判断；市场规模需另行调研，本稿不给具体数字。

PRD §5、§16（影响与可能性为主观判断）9
坑点 ①　跳单

第一次撮合成功后，平台对双方的价值迅速下降

声乐一对一是强关系、长期固定老师的服务；私下交易能各省掉 20–30% 抽成。这是家教撮合平台最常见的死因。
光靠禁止没用，要让离开平台的成本高于抽成。

让学生的价值留在平台

  • 看乐分级测评与证书
  • 学习档案与进度（换老师也保留）
  • 教材、作业、练习打卡
  • 课时资产

让老师离开有成本

  • 认证等级与平台数据挂钩，决定课酬与派单优先级
  • 平台承担收款、开票、纠纷兜底
  • 早期“年费＋低抽成”，降低私下交易动机
  • 监测：平台学员停课而老师仍活跃的比例
PRD §5.110
坑点 ②　质量

一张证书管不住三个月后怎么教

否则创始人要解决的“乱教”，会在自己的平台上重现，而且算在看乐头上。

认证按体系线＋等级颁发，有有效期
→
过程数据测评进步、出勤、作业、评价
→
抽查课堂录音 / 视频按标准评分
→
预警工单指标低于阈值或收到投诉
→
复训 / 降级 / 暂停暂停后系统自动禁止接新课、收新款

同时要解决培训产能：如果只有创始人能讲透教学法，年认证人数有硬上限。要尽早建立“培训师的培训”，创始人逐步从讲课转到定标准、审标准。

PRD §5.2、§5.511
坑点 ③　合规（需律师按城市确认）

“统一收款”的方向对，但钱不能进看乐账户再转出

事项风险对策方向
二清平台先收款再分给老师，可能构成资金二次清分持牌通道分账（微信支付服务商分账 / 电商收付通），资金直达收款方
预收费监管多地对艺术类培训预收费有课时或期限上限、监管账户要求课时包规格受城市参数约束，按课消释放
未成年人场地营业性歌舞娱乐场所不得允许未成年人进入（KTV 包房只适合成人）场地分类，系统限制少儿课只能约合规场地；老师须有入职查询
特许经营以“加盟”收费适用特许经营条例（“两店一年”、备案、披露）确认主体资质，或设计为“认证＋平台服务”
个税与劳动关系个人老师收入代扣、发票；管得过细可能被认定为劳动关系明确代扣方；平台管标准与质量，老师自主接课
PRD §5.7–5.9、§1412
坑点 ④⑤　冷启动 · 激励漂移 · 定价

三个会悄悄拖垮项目的坑

冷启动与本地密度

“就近约课”要求目标商圈 3 公里内有 3 位以上可约老师，否则约不到人，两边都留不住。

→ 先带存量学生，一城打透再复制，不撒点。

激励漂移

按课时抽成，所有运营动作会自然向“多卖课时”靠拢，最终变成又一个卖课平台。

→ 北极星用“达标老师 × 学生进步”，课时 GMV 只看健康度。

一对一与“常态化”冲突

一对一单价高，难以普及。

→ 主推 4–6 人小组课：学生更便宜，老师时薪更高；理论类做线上小组课，绕开场地。

全新项目 · 第一天就要做对的事

设计点为什么不能后补
多主体归属每笔订单、课时、课酬都要知道属于谁、结算给谁（平台 / 机构 / 独立老师 / 学员）
持牌分账支付通道上线后很难迁移；从源头避开二清

不可变流水课时、资金、课酬的每次变化都追加流水，不改余额

data-model.md §0、§518
数据模型概览

六个领域，三条主线

①

身份与主体

账号、学员、监护人、老师、机构、收款方

②

课程体系

体系线、级别、教案、测评标准（版本化）、课程规格

③

培训与认证

期次、考核、认证、认证事件、背景审查

④

交易与资金

课时包与价格版本、订单快照、支付、分账、退款、对账

⑤

课时与课堂

课时批次与流水、课堂、出勤、场地、课酬流水、结算单

⑥

学习与质检

学习档案、作业、测评结果、评价、抽查、质检工单、投诉

钱的线

价格版本 → 订单 → 支付 → 分账到收款方

课的线

课时批次 → 冻结 → 课堂消费 → 课酬 → 结算

质量的线

认证 → 过程数据 → 抽查 → 工单 → 认证变更
