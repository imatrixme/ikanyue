## 1. 一句话

> 看乐不再以“卖了多少节课”衡量自己，而是以“有多少合格的老师在按看乐的方法教、有多少学生因此真正进步”衡量自己。平台是推广教学法的工具，不是目的。

---

## 2. 前因：为什么要做这件事

### 2.1 行业现实

1. **天赋论与成名论**：大众把学不好归因于“没天赋”，把学音乐的意义理解为“成名”或“考级加分”。音乐没有被当作与数理化同等的基础素养来学习。
2. **师资质量参差**：大量老师自己没理解透发声、听觉、乐理的原理，技艺本身也有欠缺，教学多凭个人经验和模仿。学生学不好又被归因于天赋，形成恶性循环。
3. **缺少可执行的教学标准**：现有考级体系主要回答“考什么”，很少回答“老师每节课该怎么教、学生每一步该达到什么”。教学过程本身不可见、不可评。

### 2.2 看乐现实

1. **线下门店重资产**：租金、装修、人员成本高，单店模型复制慢、风险大。
2. **获客难**：线下获客依赖地推和口碑，半径有限、成本高。
3. **影响力天花板**：哪怕门店经营得再好，一家机构能直接覆盖的学生数量相对全民素质的目标微不足道。
4. **已有资产**：看乐有一套自己的教学理念与方法，有直营教学经验，有一批认同理念的老师与学生。这是本项目唯一真正不可复制的起点。

### 2.3 创始人的设想

```text
师资培训 → 课程体系认证 → 加盟成为看乐认证老师
                                   ↓
学生在看乐平台就近约课 → 在机构琴房 / 临时场地上课
                                   ↓
         看乐统一收款、统一结算 → 学生是在“跟看乐学”
```

核心意图有三：轻资产扩张、推广教学法、通过统一收款解决财务问题。

## 3. 核心判断

### 3.1 这是两门生意，不是一门

| | A. 推广体系、认证师资 | B. 就近约课撮合 |
|---|---|---|
| 本质 | 标准输出（类似奥尔夫、柯达伊、铃木、英皇的传播路径） | 双边市场（类似家教 O2O） |
| 壁垒 | 教学法、分级标准、认证公信力 | 本地密度、获客效率 |
| 主要风险 | 体系能否被标准化、培训产能 | 冷启动、跳单、获客成本 |
| 与创始人理念 | 直接对齐 | 若不加约束，会把指标拉回“课时数” |

**结论**：A 是目的，B 是手段。顺序必须是 A → 工具 → B。

### 3.2 因果链：为什么先体系、后撮合

```text
没有可考核的体系   → 认证只能看“感觉” → 认证变成卖证 → 品牌被稀释
没有过程数据      → 无法证明“跟看乐学更有效” → 学生没理由通过平台 → 跳单
没有本地老师密度   → 就近约课约不到人 → 学生流失 → 老师没生源 → 老师流失
```

反过来：

```text
可考核的体系 → 认证有公信力 → 认证老师愿意付费并按体系教
           → 平台记录学生进步（测评 / 档案 / 级别）
           → “跟看乐学”有可见的证据 → 学生与家长信任品牌
           → 老师离开平台会失去生源与学生档案 → 跳单减少
           → 本地老师足够多 → 撮合才有意义
```

这条链是本项目的**飞轮**，后续所有功能都应当能指出它在推动飞轮的哪一环。

## 4. 机会

1. **“教学过程标准”是空位**：市场上不缺考试标准，缺的是“怎么教”的标准，以及能够证明教学有效的过程数据。看乐的理念恰好落在这里。
2. **老师的真实痛点**：大量独立声乐老师缺系统方法、缺稳定生源、缺品牌背书，还要自己处理收款、排课、续费。体系、生源、工具、结算四件事打包，对他们有真实价值。
3. **小机构的真实痛点**：小型琴行、工作室有场地、有学生，但缺教研体系和差异化品牌。认证机构身份可以成为他们的招生卖点。
4. **轻资产的复制速度**：一旦体系标准化、培训可复制，扩张速度取决于培训产能，而不是门店资金。
5. **常态化定位带来的增量人群**：把音乐学习定位为“基础素养”而不是“成名之路”，触达的是原本因“我没天赋”而不敢学的成人和普通家庭，这部分人群现有机构覆盖不足。小组课是与这个定位天然匹配的形态。

> 注：上述为方向判断，市场规模需要另行调研，不在本文给出具体数字。

## 5. 坑点（详细）

每条按“现象 → 后果 → 对策”展开，并标注影响与可能性（高 / 中 / 低，主观判断）。

### 5.1 跳单（影响 高 / 可能性 高）

- 现象：声乐一对一是强关系、长期固定老师的服务。第一次撮合成功后，学生和老师私下交易可以各自省掉平台抽成。
- 后果：平台只承担了获客成本，没有拿到复购收入；家教 O2O 的典型死因。
- 对策：
  - 让价值留在平台：分级测评与证书、学习档案、教材与作业、课时资产只在平台内有效。
  - 让老师离开有成本：认证等级与平台数据挂钩，等级决定课酬与派单优先级；平台承担收款、开票、纠纷兜底。
  - 抽成定价克制：早期以“认证年费 + 低抽成”为主，降低私下交易动机。
  - 监测指标：“平台学生停课、但老师仍活跃”的比例。

### 5.2 认证不等于持续质量（影响 高 / 可能性 高）

- 现象：一次培训 + 一张证书，管不住三个月后怎么教。
- 后果：认证老师“乱教”，正是创始人要解决的问题在自己平台上重现，且品牌受损。
- 对策：
  - 认证有有效期、需复训；认证有等级，可升可降。
  - 质检闭环：学生阶段测评进步、出勤率、学生评价、作业完成率、课堂录音抽查。
  - 明确的暂停与吊销规则，暂停后系统自动禁止接新课、收新款。

### 5.3 冷启动与本地密度（影响 高 / 可能性 高）

- 现象：“就近约课”要求老师在地理上足够密集，否则学生约不到人。
- 后果：两边都留不住，平台空转。
- 对策：
  - 第一阶段不做撮合，先让认证老师带自己的存量学生上平台。
  - 撮合只在一个城市开放，且以密度门槛为前提（例如目标商圈 3 公里内有 3 位以上可约认证老师）。
  - 一城打透后再复制，不撒点。

### 5.4 获客成本（影响 高 / 可能性 中）

- 现象：看乐品牌认知度有限，向 C 端直接买流量可能比抽成还贵。
- 对策：最便宜的获客是认证老师自带的存量学生和学员转介绍；对 C 端的品牌投入主要用于“音乐教育常态化”理念内容，而不是直接买量。

### 5.5 培训产能与创始人时间（影响 高 / 可能性 高）

- 现象：如果只有创始人能讲透教学法，年认证人数存在硬上限。
- 后果：扩张速度被卡死，或为扩张降低认证门槛。
- 对策：尽早建立“培训师的培训”：分级讲师体系、标准化培训课件与考核题库、试讲评分表。创始人逐步从“讲课”转到“定标准、审标准”。

### 5.6 品牌连带责任（影响 高 / 可能性 中）

- 现象：“学生是在跟看乐学”，意味着加盟老师的事故、纠纷、不当行为都会算到看乐头上。
- 对策：准入背景审查（含面向未成年人的强制性查询）、行为准则、投诉处理时限、保险、明确的合同责任划分。

### 5.7 未成年人与场地（影响 高 / 可能性 中）

- 现象：KTV 包房等娱乐场所不适合未成年人；《未成年人保护法》规定营业性歌舞娱乐场所不得允许未成年人进入。
- 对策：场地分类管理，系统层面限制“少儿课程只能预约合规场地”；成人可放宽。优先发展合作机构琴房、共享琴房、社区空间。

### 5.8 资金合规（影响 高 / 可能性 高，若设计不当）

- 二清风险：平台先把钱收进自有账户再分给老师或机构，可能构成资金二次清分。对策：使用持牌支付机构的分账能力（如微信支付服务商分账、电商收付通），资金直接从通道分到各收款方。
- 预收费监管：多地对校外培训（含艺术类）的预收费有课时或期限上限及资金监管要求。对策：课时包规格设计受上限约束，并支持按课消释放。
- 个人收款与个税：独立老师作为个人收款方时，涉及个税代扣代缴、发票等问题。对策：明确由谁代扣、如何开票，必要时借助灵活用工 / 税务合规服务商。

### 5.9 加盟与劳动关系（影响 中 / 可能性 中）

- 特许经营：以“加盟”名义招募并收取费用，适用《商业特许经营管理条例》（“两店一年”、备案、信息披露）。对策：确认主体资质；或在合同上设计为“认证 + 平台服务”而非“特许加盟”。是否可行需律师判断。
- 劳动关系：平台对老师管得越细（排班、定价、考勤），越可能被认定为劳动关系。对策：平台管“标准与质量”，老师自主决定接课时间。

### 5.10 激励漂移（影响 高 / 可能性 高）

- 现象：平台按课时抽成，所有运营动作会自然向“多卖课时”靠拢。
- 后果：背离“不是看上了多少节课”的初衷，最终变成又一个卖课平台。
- 对策：北极星指标用“达标认证教师数 × 学生测评进步”，课时 GMV 只作为健康度指标。

### 5.11 定价与“常态化”的冲突（影响 中 / 可能性 高）

- 现象：一对一单价高，难以“常态化”。
- 对策：主推小组课（4–6 人）：学生单价降低，老师时薪反而更高；一对一作为进阶选项。理论、视唱练耳类可以做线上小组课，彻底绕开场地问题。

### 5.12 体系被复制（影响 中 / 可能性 中）

- 现象：教案和方法一旦发出去，可能被拿走另起炉灶。
- 对策：真正的护城河是“认证公信力 + 学生进步数据 + 持续教研更新”，而不是教案本身。教案可以开放，认证与测评必须在平台内。

## 6. 目标与非目标

### 6.1 目标（MVP，约 3–9 个月）

- G1：把看乐教学法沉淀为可考核的分级体系（大纲、教案、测评标准、教师考核标准）。
- G2：完成首批 20–50 位认证老师的培训与认证。
- G3：认证老师使用平台管理其现有学生的排课、课时、作业、测评。
- G4：所有学员付款经持牌通道分账结算，看乐不经手二清资金。
- G5：建立教学质量闭环，能按老师维度看到质量数据并执行暂停。

### 6.2 非目标（MVP 明确不做）

- 学生在平台上寻找新老师（撮合 / 就近推荐）。
- 场地在线预订与场地方结算。
- 多城市运营。
- 原生 App、自研视频课、积分商城、复杂营销。

## 8. 商业模式

### 8.1 收入结构（假设，待创始人拍板）

| 收入 | 说明 | 早期占比预期 |
|---|---|---|
| 培训认证费 | 每期师资培训与考核 | 主要 |
| 认证年费 / 平台服务费 | 维持认证、使用工具、教研更新 | 主要 |
| 课时抽成 | 学员课时包分账中的平台份额 | 次要（早期刻意偏低） |
| 教材与测评 | 分级教材、测评与证书 | 次要 |

### 8.2 单节课的钱去哪（假设）

以一节 250 元的声乐课为例，抽成 25%：

```text
学员支付                 250.00 元
支付通道费（约 0.6%）     1.50 元
平台份额                 61.00 元  （扣除通道费后）
老师 / 机构所得          187.50 元 （场地成本由老师或机构自理）
```

抽成比例、通道费承担方、场地成本归属都是待定参数。

## 9. 规模推演（假设）

单个认证老师：每周 15 节平台课时 × 4 周 = 60 节 / 月；客单价 250 元；月 GMV 1.5 万元；平台抽成 25% 约 3750 元。

| 阶段 | 认证老师 | 月 GMV | 平台月抽成 |
|---|---|---|---|
| 单城验证 | 30–50 | 45–75 万元 | 11–19 万元 |
| 3–5 城 | 200–300 | 300–450 万元 | 75–110 万元 |
| 约 20 城 | 1000+ | 1500 万元+ | 375 万元+ |

**推演结论**：规模的上限不是技术，而是三件事：培训产能、单城老师密度、获客成本。早期收入更可能以培训认证费与年费为主，这与“推广体系”的初衷一致。

## 10. 路线与过关条件

| 阶段 | 时间（假设） | 做什么 | 过关条件 |
|---|---|---|---|
| 0. 体系产品化 | 0–3 个月 | 分级大纲、教案、测评标准、教师考核标准；开 1–2 期付费培训 | 老师愿意付费；通过率合理；结业后确实按体系教学 |
| 1. 工具与结算 | 3–9 个月 | MVP 上线：认证老师带存量学生上平台；分账结算；质检闭环 | 学生留存、测评进步、老师续认证；老师认为用平台比私下收款更省事 |
| 2. 单城撮合 | 9–18 个月 | 在一个城市开放就近约课、合作场地、线上理论小组课 | 平台来源学生复购率、跳单率、老师平台收入占比达标 |
| 3. 多城复制 | 18 个月后 | 城市合伙人 / 认证机构复制，先完成合规 | 新城市达到密度门槛后才开放撮合 |

每个阶段不过关就不进入下一阶段，而是回到上一阶段修正。

## 11. MVP 功能需求

### 11.1 体系与认证（运营后台）

- F-101 课程体系管理：体系线（如成人声乐、少儿声乐、视唱练耳）→ 级别 → 单元 → 课；每课包含教学目标、教案、作业模板。
- F-102 测评标准管理：每个级别的测评项、评分规则、通过线；版本化，历史测评按当时版本解释。
- F-103 培训期次与报名：期次、讲师、学员（准老师）、费用、考核记录（笔试、试讲评分）。
- F-104 认证管理：按“体系线 + 等级”颁发认证，含有效期；支持复训续期、暂停、恢复、吊销，每次变化记录原因与操作人。
- F-105 背景审查记录：面向未成年人授课的老师必须有有效的查询记录，否则不能接少儿课程。

### 11.2 教师端（小程序）

- F-201 学员管理：邀请存量学员加入（扫码 / 链接），学员归入某体系线与级别。
- F-202 排课与上课：创建课堂（时间、形式一对一 / 小组、场地）、签到、填写课堂反馈。
- F-203 作业与测评：按体系布置作业；按测评标准录入阶段测评，达到通过线后申请晋级。
- F-204 收入：查看每节课的课酬流水与结算单。
- 约束：认证暂停或过期时，不能创建新课堂、不能向学员发起新的课时包购买。

### 11.3 学员 / 监护人端（小程序）

- F-301 购买课时包：只能购买自己老师所获认证范围内的课时包；遵守预收费上限。
- F-302 课表与请假：查看课表、确认或请假（请假规则由课时包条款决定）。
- F-303 学习档案：级别进度、测评结果、作业记录、课堂反馈；档案属于学员与看乐，换老师时保留。
- F-304 课后评价：每节课或每阶段评价老师，作为质检输入。
- F-305 监护人：未成年学员必须绑定监护人，由监护人付款与授权。

### 11.4 交易与结算

- F-401 课时包与价格版本：规格、价格、课时数、有效期、退款条款；发布后不可修改，只能发布新版本。
- F-402 下单与支付：通过持牌通道支付，订单快照包含价格、条款、老师、分账比例。
- F-403 分账：按课消或按周期，将老师 / 机构份额分给对应收款方；平台不中转资金。
- F-404 退款：按剩余课时与条款计算；已冻结（已排课）的课时先处理课堂。
- F-405 对账：通道账单与平台流水逐笔核对，差异进入人工处理。

### 11.5 质检（运营后台）

- F-501 教师质量看板：出勤率、学员留存、测评进步、作业完成率、评价分布。
- F-502 抽查：要求老师上传指定课堂的录音或视频片段，质检按标准评分。
- F-503 预警与处理：指标低于阈值或收到投诉时生成质检工单；可建议复训、降级、暂停。
- F-504 投诉：学员 / 监护人投诉入口，处理时限与结果留痕。

## 12. 关键业务规则（不变量）

- R-01：只有处于“有效”状态且覆盖对应体系线与等级的认证老师，才能创建课堂和发起课时包购买。
- R-02：少儿课程只能安排在允许未成年人进入的场地，且授课老师背景审查有效。
- R-03：所有资金经持牌通道分账，平台账户不中转应付老师 / 机构的款项。
- R-04：课时、资金、课酬的每次变化都追加不可变流水，不直接改余额。
- R-05：同一课堂同一学员最多消费一次课时；同一课堂同一老师最多结算一次课酬。
- R-06：学习档案与测评记录属于学员与平台，老师离开或被吊销后档案保留，学员可转给其他认证老师继续。
- R-07：价格、条款、测评标准、分账比例均版本化；历史记录按当时版本解释，不回溯重算。
- R-08：客户端提交的价格、余额、分账结果不具有权威性。
- R-09：预收费规格不得超过当地监管上限（参数化配置）。
- R-10：认证状态变更、退款、分账规则变更必须记录操作人与原因。

## 13. 指标

- 北极星：**达标认证教师数**（有效认证且质检达标）× **学员阶段测评通过率**。
- 体系侧：培训报名转化率、认证通过率、复训率、讲师人数。
- 教学侧：学员 3 / 6 个月留存、测评进步、作业完成率、评价分。
- 平台侧：平台学员占老师总学员比例、跳单率代理指标（平台学员停课而老师仍活跃）。
- 财务侧：课时 GMV、平台收入构成（培训 / 年费 / 抽成）、退款率、对账差异数。

课时 GMV 是健康度指标，不作为团队首要考核指标。

## 14. 合规清单（需律师确认）

| 事项 | 需要确认的问题 |
|---|---|
| 支付与分账 | 用哪个主体申请服务商 / 电商收付通；个人老师能否作为分账接收方；手续费承担 |
| 预收费监管 | 首个城市对艺术类培训预收费的课时与期限上限、资金监管账户要求 |
| 校外培训资质 | 面向未成年人的线下艺术培训，平台与认证机构各自需要的审批或备案 |
| 特许经营 | 是否构成特许经营；主体是否满足“两店一年”；备案与信息披露 |
| 劳动关系 | 平台对老师的管理边界，避免被认定为劳动关系 |
| 个税与发票 | 个人老师收入的代扣代缴、发票开具 |
| 未成年人保护 | 教师入职查询、场地限制、监护人授权、未成年人个人信息保护 |
| 个人信息 | 课堂录音 / 视频抽查的授权、存储与删除 |

## 15. 待创始人拍板的问题

1. 首批客群：成人、少儿，还是两者都有？
2. 加盟主体：独立老师、小机构，还是两者都有？
3. 收入结构：以培训认证费 + 年费为主，还是以课时抽成为主？早期抽成比例多少？
4. 课时包能否在不同认证老师之间通用？（通用更像“跟看乐学”，但结算更复杂）
5. 教学法目前能否写成可考核的标准？谁来写，多久写完？
6. 首个验证城市是哪里？现有多少老师与学员可以作为种子？
7. 用哪个公司主体做支付服务商与签约主体？
8. 创始人愿意把多少时间从“讲课”转到“定标准、培养讲师”？
