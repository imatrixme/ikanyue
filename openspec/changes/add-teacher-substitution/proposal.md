## Why

小工作室人员流动频繁：老师临时请假要找人代课，老师离职要把手上的学员和课交给别人。

现在学员课时记在「学员 + 课程」上，不绑定老师，所以换老师不需要转移课时。但课一旦排好，就没有任何办法换老师：

- 学员约课确认后生成的课，主讲老师固定是被约的老师，没有「换人」的命令；
- 原老师请假只能被标为缺席，而结算要求一位已确认的主讲老师，于是这节课确认不了、课时扣不了；
- 硬让老板代确认，课酬会记到没上课的原老师名下；
- 老师离职后，他未来已排的课一直挂在他名下，代课老师看不到；他没处理的约课申请没人接，只能等超时。

## Product decisions (confirmed 2026-10-30)

1. **单节课换老师（A）**：
   - 老板对一节还没确认的课「换老师」，开课前后都可以；
   - 只换这节课的主讲老师，学员、课时、预约记录都不动；
   - 代课老师在自己的待确认列表里看到这节课，由他确认上课，课酬记给他。
2. **离职交接（B）**：老板选「离职老师 → 接手老师」，先预览再一次完成：
   1. 离职老师未来所有未确认的课，改由接手老师上；
   2. 离职老师没处理的约课申请统一婉拒，学员可以重新约；
   3. 关闭离职老师的开放预约；
   4. 停用离职老师账号。
   - 学员课时不需要任何转移。
3. **只有老板能换老师**：老师之间私下调课也由老板来换，避免课酬纠纷。
4. **已确认的课不直接改老师**：发现已确认的课其实是别人代上的，先撤销确认、再换老师、再重新确认，沿用现有的课酬冲正。
5. **不新增「归属老师」概念**：续课提醒按「最近给谁上过课」推算，交接后自然落到接手老师。

## What Changes

- **换老师命令**：
  - 新增 `substituteTeacher`：把一节未结算课的主讲老师换成另一位在职老师；
  - 原主讲那一行标为 `cancelled`，新老师以 `assignmentSource: substitute` 加入，状态 `planned`；
  - 检查新老师在这个时间段有没有别的课；
  - 写审计和 outbox 事件。
- **离职交接命令**：
  - 新增 `handoverTeacher`，带预览查询；
  - 一个事务内完成：换课、婉拒约课申请、关闭开放预约、停用账号；
  - 有时间冲突时整单拒绝，预览会列出冲突的课。
- **视图跟着实际上课老师走**：
  - 学员看到的课和预约详情显示当前主讲老师，不显示已被换下的老师；
  - 已被换下的原老师不能再改期或取消这节课的预约，改由老板处理。
- **小程序**：
  - 工作室有两位以上老师时，老板的工作台出现「老师」模块；
  - 新增老师列表页、老师详情页（他未确认的课、逐节「换老师」、「离职交接」）；
  - 待确认上课列表里，老板也可以对每节课「换老师」。
- **网关**：`mapi.json` 新增对应接口。

## Non-goals

- 不做老师之间自助发起、对方接受的调课。
- 不改已结算课的老师；不做离职老师课酬结清。
- 不自动给接手老师开放预约时段（时间安排是老师自己的事），预览里会提示哪些课程接手老师还没开放预约。
- 不推送换老师通知，本期只写 outbox 事件，学员在课程和预约里看到新老师。
- 不做「归属老师」，不搬迁任何课时。
- 交接不能自动撤回：改错了可以逐节再换回，账号在网页后台重新启用。

## Capabilities

### New Capabilities
- `teacher-substitution`：老板为单节课换老师、离职交接，学员视图显示实际上课老师。

### Modified Capabilities
- 无。`owner-workbench` 仍在 `add-owner-workbench` 变更中、尚未归档，本提案只在新能力里描述工作台新增的「老师」模块。

## Impact

- `kanyue.server`：
  - `coursecredit` 新增 `substituteTeacher`、`handoverTeacher` 及预览查询；
  - 工作台模块新增老师相关路由，复用 `managing(administrator)` 实时校验；
  - 学员课程视图过滤已取消的老师行；
  - 预约命令对已换老师的课改为校验当前主讲；
  - 测试与契约测试。
- `ikanyue.mini`：工作台「老师」模块、老师列表页、老师详情页、换老师弹窗、交接预览；单测与 `test:live`。
- `kanyue.gateway`：`internal/exposure/mapi.json` 新增接口。
- 数据：不新增集合与字段；沿用 `session_teachers` 的 `substitute` 来源与 `cancelled` 状态。
- 依赖：无新增。
